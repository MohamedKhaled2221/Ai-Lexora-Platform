# Templates

The project identifies NDA, Employment Contract, and Partnership Agreement as
the initial supported document types, subject to the final approved list.

The actual legal template text must come from approved/legal source material.
This repository intentionally does not invent legal clauses.

Use stable placeholders such as:
- `{{party_a_name}}`
- `{{party_b_name}}`
- `{{effective_date}}`

Approved M5 clauses are inserted with:
`{{CLAUSE:INSERTION_KEY}}`
