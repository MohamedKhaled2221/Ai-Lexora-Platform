# AI-Lexora Package 3/4 Acceptance QA

This directory contains synthetic, test-only legal data.

Nothing under qa/acceptance is approved production legal content.

## Principles

- Never use synthetic clauses as real legal advice.
- P4 ACL failures are automatic test failures.
- P4 superseded/review_required/unversioned evidence must not support answers.
- Unsupported generated claims are automatic failures.
- Citations must resolve to actual retrieved evidence.
- P3 must never export ungrounded or untraceable legal text.
- Production P3 remains disabled until approved templates are provided.
